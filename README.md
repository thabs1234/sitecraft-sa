# SiteCraft SA

Done-for-you websites for South African small businesses. R1,500 setup + R450/mo, owner-editable, R0 hosting (GitHub Pages).

## What's in this repo
- `index.html` / `styles.css` / `script.js` — the SiteCraft SA marketing/lead site.
- `clients/`, `samples/`, `proposals/`, `outreach/`, `marketing/`, `pdf/` — client delivery + lead-gen assets.
- `claude-skills/` — agent skills used to build/deliver sites.

## Stack
Static HTML/CSS/JS. No framework, no build step. Deploy to GitHub Pages.
